# ReFlood Milestone 182: custom map selection

## Changes

- The settings menu now offers **Choose Custom Map** immediately above **Start Singleplayer Game**. The browser starts in `./custom/levels`; if that directory is absent, it starts in `./`. It lists directories and `*_header.bin` files, supports keyboard, mouse, and gamepad navigation, and checks a selected map before starting.
- A custom header loads its matching tilemap and trigger payload while using the player's extracted `data/` graphics and sound. The selected map runs as a single level; on completion or game over, control returns to settings. The original campaign and its high scores are unaffected. Restart reloads the selected custom map.
- The editor sidebar now reads **T: TILE DESCRIPTION**, its startup message reads **LEVEL 01**, and the lower-left custom-output statement was removed.
- The settings and browser layout fit the game's 320×208 canvas; the browser's help and error text remain visible.
- Updated the README and tests for the new menu action and custom header loading.

## Verification

- Compiled the SDL2 game and editor with `-Wall -Wextra -Wpedantic` without warnings.
- Passed the core, multiplayer, SDL input, editor level round-trip, and editor SDL UI tests using locally extracted original data. The SDL UI test ran with the dummy video driver.
- Loaded a custom-named level generated by the editor using the game loader (bank A, start at 64,112). Browser selection also passed an SDL input test.

The source ZIP contains no extracted copyrighted data. Its empty `data/` directory has mode 755 and all ZIP timestamps are normalized to 2025-01-01. A visible desktop playthrough was unavailable.
